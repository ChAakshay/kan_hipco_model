Hi! You can run this application in 2 very simple ways:

--------------------------------------------------------------------------------
OPTION 1: THE FASTEST & EASIEST WAY (Zero installation, works on any computer)
--------------------------------------------------------------------------------
1. Simply double-click:
   hipco_kan_dss_app.html

2. It will open immediately in your web browser (Chrome, Edge, Safari, Firefox).
3. That's it! No Python, no terminal, and no installation required.
   You can adjust reactor sliders, test targets, view the 3D Pareto frontier,
   and explore all 5 tabs right inside your browser.


--------------------------------------------------------------------------------
OPTION 2: THE FULL SCIENTIFIC AI APP (With live PyTorch inverse optimization)
--------------------------------------------------------------------------------
If you have Python installed and want to run the full PyTorch neural network
backend with real-time autograd optimization:

* On Windows:
  Double-click: RUN_APP.bat

* On Mac / Linux:
  Double-click or run in Terminal: ./RUN_APP.sh

* Or from any Command Prompt / Terminal:
  python launcher.py

This automatically checks dependencies, starts the local server at
http://localhost:8050/, and opens your browser.
